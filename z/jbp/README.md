# 聚宝盆 JBP｜经营战略研究网站 V2.0

打开 `index.html` 即可浏览，除外部资料链接外均可离线使用；无需安装依赖或启动服务。

## 阅读路线（金字塔原则）

1. `index.html`：执行摘要与业务负责人决策入口（先给结论）
2. `trend.html`：2016—2025十年业绩与2026H1（先看现象、再辨原因）
3. `model.html`：聚宝盆合作模式及服务价值
4. `market.html`：竞品体量、业务口径和直接/替代竞争
5. `positioning.html`：院外医药供应链生态位与战略取舍
6. `strategy.html`：六大重点发力方向（解决方案）
7. `execution.html`：0—24个月实施、阶段门槛与组织安排
8. `economics.html`：单位经济、KPI、情景测算与增量实验
9. `sources.html`：公开资料、财务统计口径、待验证假设

**重要口径提醒：** 公开资料无法核实JBP独立业务历年GMV、会计收入和集团占比；不可将111集团B2B收入、MP平台服务收入或重点推广商品收入直接当作JBP数据。2026H1同比比较2025H1，不与2025全年直接同比。

## 质量核对

- 逐页检查9页导航、锚点链接与返回主页链接。
- 历史年度营收与同比均按财报披露的人民币千元数复算；2026H1由2025/2026两个季度的B2B、B2C收入相加，避免半年度/全年比较。
- B2B分部收入、MP服务收入、JBP独立业务数值分开呈现；不可将三者混同。
- 前述材料中的引文与优先级标签显示残留已清理。
