办公利器

约 1613 字大约 5 分钟

2026-04-09

学习

  • 外语【Relingo】 AI 驱动的外语学习工具（浏览器插件 + 手机 App），核心是 “上网即背词”，在浏览外文网页、看视频时自动高亮生词、翻译并生成个性化生词本，主打无痛积累词汇
  • 文献【Zotero】 免费开源的文献管理软件，核心帮你收集、整理、阅读、引用、分享学术文献与研究资料，学生/科研必备
  • 文献【小绿鲸】 集翻译、笔记、文献管理、文献汇报、写作功能于一体的云端英文文献阅读器
  • 笔记【Typora】 Markdown编辑器，支持实时预览，自定义主题，文件树，目录树等
  • 笔记【Obsidian】 以本地 Markdown 文件为核心的个人知识管理与笔记工具，免费，双向链接 + 图谱。扩展性极强，提供丰富的主题、插件（例如 AI 插件：Copilot，Text Generator）
  • 笔记【Logseq】 以结构化大纲和块级链接为特色的笔记软件，兼容Markdown 与 Org-mode，文件按日期和页面自动组织，对于阅读和标注 PDF 文件更友好。内置 Git 同步、查询、任务管理，虽然插件较少但核心功能开箱即用
  • 记忆【AnkiDroid】 以卡片的方式记忆知识碎片, 记忆卡片

数学

  • 综合【Mathematica】 全能数学软件，易上手，擅长符号计算
  • 几何【GeoGebra】 几何绘图软件，免费，有在线版
  • 几何【Geometer's Sketchpad】 几何画板, 上学时学到的数学软件，几何作图方便
  • 几何【Efofex】 几何工具, 支持化学公式和统计图等
  • 统计【G*Power】 在AB实验中计算最小样本量
  • 统计【ABetter】 自己写的AB实验工具包
  • 动画【Manim】 制作数学动画的Python库

码字

  • 文本【Sublime Text】文本编辑, 免费
  • 文本【CotEditor】文本编辑, 免费
  • 文本【Notepad++】 文本编辑, 免费，插件较丰富。支持多种编程语言的语法高亮
  • 五笔【小狼毫】 RIME（中州韵输入法引擎）, 支持拼音、五笔、双拼等多种常见的输入方案

    • 【空山明月/Rime五笔】已经配置好的五笔输入方案，只做少量修改即可做到与极点五笔相似的效果

    • 【空山明月/中书君-Rime管理器】RIME可视化管理工具

  • 五笔【搜狗五笔】不折腾，Win11友好，与极点五笔类似
  • 五笔【QQ五笔】 不折腾，Win10及以下友好，在Win11上偶尔会崩溃，与极点五笔类似
  • SQL【DataGrip】 关于SQL的IDE工具, JetBrains产品。支持多种数据库

系统工具

  • 搜索【Listary】 文件搜索与系统快捷操作辅助软件, 支持中文拼音头搜索
  • 搜索【Everything】搜索速度非常快，还可以搜索文件内容
  • 效率【AutoHotKey】Windows上的终极自动化脚本语言。
  • 效率【QTTabBar】 文件管理器插件, 多个文件夹，可以像浏览器的标签那样存在
  • 终端【MobaXterm】SSH客户端
  • 截图【Snipaste】 截图+贴图, 喜欢它的：截图、贴图、复制颜色，使用教程
  • 文件管理【Total Commander】 文件管理神器, 用过一次（仔细地）之后就爱不释手了
  • 磁盘分析【WizTree】可视化硬盘空间分析工具，自称是最快的硬盘空间分析工具
  • 数据恢复【DiskGenius】老牌数据恢复工具，公司坐落于秦皇岛
  • 软件卸载【Uninstall Tool】给电脑减负

视频、图片、音乐

  • 钢琴【Overture】专业打谱软件，可把琴谱转成mid并导入到 Synthesia 中
  • 钢琴【Synthesia】 五线谱可视化软件，即使不懂，看看也赏心悦目
  • 音乐【Audition】 音乐编辑软件，前身是 Cool Edit
  • 图片【FastStone Image Viewer】 图片浏览器, 可对图片做简单的批量处理
  • 图片【FastStone MaxView】图片浏览软件，打开速度非常快
  • 图片【BandiView】可查看压缩文件中的图片（不需要解压，即可浏览压缩文件中的所有图片）
  • 视频【PotPlayer】人性化操作，几乎可以播放所有常见格式的视频
