JBP STRATEGY / 06 OF 08

90天至24个月实施路线图

小规模验证—复制—扩张；每一阶段都设停止或放量门槛。

实施原则

先做低成本、可逆的运营试点；一旦验证有效，再扩张区域、商品和预算。使用阶段门槛（stage gate）避免规模先行。

EXECUTION / 01

最重要的前90天：四个工作包

DAY 01—15

统一经营口径

确认JBP边界、货权、合同类型、交易收入和成本归集；输出业务损益树及基线看板。

Owner：业务负责人 + 财务BP
DAY 16—30

确定试点组合

筛选约20家供应商、100—200个SKU和可比药店组；建立商品准入、运营、退出标准。

Owner：招商 + 类目运营
DAY 31—60

开展可归因动销试点

完成选品、试销、触达与对照组设计；每周复盘转化、复购、履约与费用。

Owner：商品运营 + 数据分析
DAY 61—90

经营复盘与放量决策

评价供应商增量、贡献利润、履约质量；决定扩大、修改或终止项目。

Owner：JBP经营委员会
EXECUTION / 02

阶段门槛：不满足就不扩大投入

阶段必须交付放量门槛
第90天经营基线、试点数据、合规审查能清晰核算贡献利润，且样板组出现可信的增量信号
第6个月商品运营SOP、供应商经营看板多组可重复的正向单位经济，履约质量达标
第12个月跨品类/跨区域复制结果剔除补贴后的留存、复购与利润仍稳定
第24个月成熟经营体系和产品化收费收入结构更健康，持续贡献利润与现金流改善
EXECUTION / 03

组织设计：一个Owner + 共同利润目标

建议用跨职能小队负责“供应商+品类+药店”的闭环，而不是各部门按局部指标分别优化。

JBP 业务负责人 / P&L Owner
招商 / 供应商经营签约质量、留存
商品 / 药店运营新增采购、复购
供应链 / 履约交付、库存、成本
数据 / 财务BP实验、核算、复盘
法务 / 质量合规准入、追溯、风险
EXECUTION / 04

管理节奏建议

运营层

每周 · SKU经营会

看动销趋势、复购、临期、缺货、毛利、触达实验。决定具体加减资源。
商务层

每月 · 供应商经营会

看留存、联合经营计划、服务收益、价格与渠道冲突、结算问题。
决策层

每季度 · 战略复盘会

评价贡献利润、品类扩张、仓配经济性、组织能力和下一阶段预算。
EXECUTION / 05

年度目标应先定基线，再定挑战值

指标12个月挑战性假设说明
月度贡献利润同口径 +30%需核实当前是否已为正
90天SKU动销率+10个百分点用批次口径防止幸存者偏差
180天供应商留存+8个百分点需剔除非正常签约
单位履约成本−10%同时约束及时交付
近效期损耗率相对−20%明确责任分摊
重大质量与监管违规0起刚性约束，不以增长换合规

数字为管理讨论起点，未得到JBP内部基线支撑，不应直接作为正式承诺。
