REFERENCES / 02

统计口径与判断边界

指标可以说明什么不可以说明什么
集团营收企业总体业务体量不能代表医药B2B市场份额
分部业务收入某类业务确认的会计收入与其他公司的GMV不能相加比较
GMV / 交易规模平台促成或实现的交易金额不等于收入，更不等于利润
市场份额同一市场定义下企业占比没有一致的市场范围和分母不能计算
JBP独立经营数据需要内部P&L及运营明细不能以111集团整体数字替代
REFERENCES / 03

核心战略假设与验证方法

H1
供应商愿为增量销售付费

验证：联合经营试点 + 付费转化 + 180天续约。

H2
药店交易数据可以提升SKU匹配效率

验证：随机对照试验的新增采购率、增量贡献利润。

H3
聚宝盆轻资产模式能提高资本效率

验证：对比库存占用、履约成本、坏账损失与利润。

H4
更精细的供应商筛选优于广撒网招商

验证：单位招商成本、首单时间、90天动销率及供应商留存。

H5
可复制的商品运营服务能形成竞争壁垒

验证：跨品类、跨区域复制效果和供应商愿意续费的比例。
