::: info 小传

1987年春，很遗憾，没有天降异像，轻轻地，我出生在一个不算偏远的小镇，有着值得怀念的童年。

说来也巧，我出生这天正好是 Pi Day，从此与数学结下了不解之缘。但奈何自己资质平平，又有颇多兴趣爱好分心，因此在数学上的造诣乏善可陈——没获得过沃尔夫奖、阿贝尔奖、华罗庚数学奖、陈省身数学奖，很快也没有资格获得菲尔兹奖了（不超过40岁），不过即便如此，却也始终保持着对数学的喜爱与热情。

除数学外，我还在计算机、音乐、棋类、闲书、摄影、无线电方面打发了很多业余时间，也体验了诸多乐趣。

2006年秋，先后在保定学院和燕山大学学习数学和统计，也是那时开始学习 Mathematica 软件，并因此结识了很多志同道合的网友。

上学期间，有两件事儿记忆深刻，一是在首届全国大学生数学竞赛（数学组）中，获取了河北赛区一等奖；二是在7年半的大学生涯中，考了11次英语四级，最后一次用了10天全力备考（曾用[拓词](https://www.towords.com/)软件花了9天时间记住了4500个大纲词汇，有一天排进前3名，几乎天都排在前10名），万幸，刚好过线。

2014年春，我毕业了，之后一直从事数据分析和商业分析工作，苦乐参半，每当有些许进步都兴奋不已。工作时经常使用 SQL 获取数据，用 Python 处理数据，用 Mathematica 等软件分析数据和绘制图表（还曾在中科院软件中心举办的 Mathematica 竞赛中获得过二等奖），用 Office 和网页呈现结果，什么都用了就是很少真正地用脑子（总是在思考事情本身，不知道功夫在诗外）。

2025年秋，写下以上个人小传，也是第一次用文字回顾出生以来的重要经历，但寥寥数笔写不下太多，愿未来能体验更精彩的人生，同时身体安康、超越百岁！

:::
