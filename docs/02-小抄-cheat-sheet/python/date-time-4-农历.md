## 1️⃣ 农历简介

### ❶ 农历的基本规则
农历不是“纯阴历”，而是**根据月相确定月份**，**根据太阳角度确定季节**的“阴阳历”。因此，在农历中最重要的 2 条规则，也分别与月亮和太阳有关：

::: tip 两条重要原则
1. **以 朔月 分月**：看月亮，看不到月亮的那天（朔月）定为每月的开始（初一）。大月有 30 天，小月有 29 天。
2. **以 中气 闰月**：看太阳，一年中日影最长的那一天定为冬至，农历规定**冬至所在的月份为冬月**（十一月称为 冬月，十二月称为 腊月）。在黄道面每隔30度为一个 中气，而每个 中气 都应该落在指定的月份，如果一个月结束了还没有到 中气，就要闰月了。

简记：**一年中第1个不包含 中气 的那个农历月，定为闰月**。
:::


::: tip 为什么要闰月？
因为 12 个农历月只有大约 354 天，比太阳年短约 11 天，如果一直不补，春节、端午、中秋这些月份对应的季节就会逐渐漂移。
为避免这种漂移，农历会在某些年份加一个月，这个额外的月就是 闰月。
古代经验上常说“十九年七闰”，已经废除，现行农历是靠的是 朔 和 中气，不是简单的“每隔几年固定闰一次”。
:::


::: tip 有哪些变化？
清顺治二年（1645 年）《时宪历》开始实施，农历从“**用平均值排历**”大体转向“**按真实天象定月定气**”；

现代则由 2017 年国家标准把这套现行规则固定下来。 它的核心变化是 **平朔/平气** → **定朔/定气**，主要影响是 **闰月分布、月序归属、节日日期和历法精度**。详见 [GB/T 33661-2017《农历的编算和颁行》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E107EA4DE9725EDF819F33C60A44B296)（发布于 2017-05-12，实施于 2017-09-01，[备用资源](/download/GBT+33661-2017--农历的编算和颁行.pdf)）。

注释：按现行历法已经**不再**有严格的“**十九年置七闰**”的规律了，参见词条[农历](https://zh.wikipedia.org/wiki/%E8%BE%B2%E6%9B%86)。
:::

### ❸ 如何闰月

简记：**一年中第1个不包含 中气 的那个农历月，定为闰月**。

::: tip 农历的编排规则
1. 以北京时间为标准时间。
2. 朔日为农历月的第一个农历日。
3. 包含节气冬至在内的农历月为农历十一月。
4. 若从某个农历十一月开始到下一个农历十一月（不含）之间有 13 个农历月，则需要置闰。置闰规则为：取其中最先出现的一个不包含中气的农历月为农历闰月。
5. 农历十一月之后第 2 个（不计闰月）农历月为农历年的起始月。

详见：[GB/T 33661-2017《农历的编算和颁行》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E107EA4DE9725EDF819F33C60A44B296)
:::


## 2️⃣ 转换：阳历→农历
```python title="阳历→农历"
from lunarcalendar import Converter, Solar, Lunar

solar_date = Solar(2026, 1, 1)
lunar_date = Converter.Solar2Lunar(solar_date)
print(lunar_date)

# 输出：
# Lunar(year=2025, month=11, day=13, isleap=False)
```


*[朔月]: 看不到月亮的那天称为朔月、新月、月缺
*[节气]: 立春，惊蛰，清明，立夏，芒种，小暑，立秋，白露，寒露，立冬，大雪，小寒
*[中气]: 雨水，春分，谷雨，小满，夏至，大暑，处暑，秋分，霜降，小雪，冬至，大寒
