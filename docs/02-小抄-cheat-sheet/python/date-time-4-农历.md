## 1️⃣ 农历简介

### 1）农历的基本规则
农历不是“纯阴历”，而是**根据月相确定月份**，**根据太阳角度确定季节**的“阴阳历”。因此，在农历中最重要的 2 条规则，也分别与月亮和太阳有关：
1. **以 朔月 分月**：看月亮，每月的开始（初一）定在看不到月亮的那天（朔月），大月 30 天，小月 29 天。
2. **以 中气 闰月**：看太阳，每个 中气 必须落在指定的月份，如果一个月结束了还没有到 中气，就要闰月。
   1. **冬至必在冬月**：包含冬至的那个月固定是十一月（冬月）。

当一年有 13 个月时，不含“中气”的那个月就是闰月。
在农历中，十一月称为 冬月，十二月称为 腊月。

::: tip 为什么要闰月？
因为 12 个农历月只有大约 354 天，比太阳年短约 11 天，如果一直不补，春节、端午、中秋这些月份对应的季节就会逐渐漂移。
为避免这种漂移，农历会在某些年份加一个月，这个额外的月就是 闰月。
古代经验上常说“十九年七闰”，已经废除，现行农历是靠的是 朔 和 中气，不是简单“每隔几年固定闰一次”。
:::

### 3）如何闰月

::: tip 怎么知道哪个月是闰月？
关键规则是这句：没有中气的那个农历月，定为闰月。
二十四节气里，有 12 个特别重要的点叫 中气，比如雨水、春分、谷雨、夏至、处暑、秋分、霜降、冬至等。
现行农历还规定：包含冬至的那个月固定是十一月。从这个“十一月”开始往后排，如果到下一个十一月之间一共出现了 13 个朔望月，那么其中 第一个不含中气的月 就是闰月；它沿用前一个月的月名，比如“闰二月”“闰六月”。
:::

现行历法在时宪历时，已废除“十九年置七闰”，以及由于当前近日点在冬季，冬季节气之间较短，十冬腊月较容易分配到中气；若采无中气置闰法，闰月较常发生在夏季。
未来因近日点进动，可能改变修改“无中气置闰”的规则，改为**在满足特定条件下，对第一个无中气之月置闰**。
条件如下：两冬月(冬至所在的月份)之间，不计冬月，若剩余11个月(即两冬至间有12次新月)，该年不用置闰；若剩余12个月(即两冬至间有13次新月)，但第一个无中气的月之前的月有两个中气，则不作闰月论，而第二个无中气的月则被视为闰月；另一方面，若第一个无中气的月之前的月只有一个中气，则即为闰月，第二个则被视为正规月（尽管无中气），月序与前一个月相同（闰月在几月后面，就称闰几月）。采用现行之定朔法，有可能会出现无中气月但无须置闰之状况。

## 2️⃣ 转换：阳历→农历
```python title="阳历→农历"
from lunarcalendar import Converter, Solar, Lunar

solar_date = Solar(2026, 1, 1)
lunar_date = Converter.Solar2Lunar(solar_date)
print(lunar_date)

# 输出：
# Lunar(year=2025, month=11, day=13, isleap=False)
```


*[朔月]: 看不到月亮的那天称为朔月、新月、月缺
*[节气]: 立春，惊蛰，清明，立夏，芒种，小暑，立秋，白露，寒露，立冬，大雪，小寒
*[中气]: 雨水，春分，谷雨，小满，夏至，大暑，处暑，秋分，霜降，小雪，冬至，大寒
