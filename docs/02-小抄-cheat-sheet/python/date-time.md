## 1️⃣ 日期小知识

**格里历**为了消除已经积累的误差，规定将**1582年10月4日**（星期四，儒略历）之后的次日定为**1582年10月15日**（星期五，格里历），即从中删除了10天。星期的顺序则保持不变。[**公历**](https://zh.wikipedia.org/wiki/%E5%85%AC%E5%8E%86)

## 2️⃣ 时间小知识


【时间戳】是一个整数（或小数），其值是从 `1970-01-01 00:00:00` 开始累计的秒数（或毫秒数）。

【闰秒】在 Python 中绝大多数情况是不考虑 闰秒 的，一般只在涉及到天文这类对时间精度要求非常高的领域时才引入 闰秒。
- 地球自转一天略长于86400秒（约0.0015秒/天），长期累积会导致天文时间（UT1）和国际原子时（TAI/UTC）不一致。
- 闰秒通常在6月30日或12月31日的23:59:59增加一秒。
- 秒闰公告通常在实施前半年发布（一月公布6月30日的闰秒，七月公布12月31日的闰秒）。
- 截止2025年，UTC比TAI少37秒。
- 闰秒对民间会带来很多问题，因此2005年就提出了要废除闰秒，预计2035年取消闰秒。
- 已经实施的[闰秒](https://zh.wikipedia.org/zh-cn/%E9%97%B0%E7%A7%92)。

## 3️⃣ 星期日历表示法

格式：`年份-W当年第几周-当周星期几`。例如`1926年8月17日`可写成`1926-W33-2`或`1926W332`。

使用年份和星期表示某一日期的格式形如`YYYYWwwD`或`YYYY-Www-D`，YYYY表示年份，其值与年月日格式中的年份略有差别；Www表示该日期所属星期是今年的第几个星期，范围在W01到W53之间；D表示该日是本星期的第几天，范围在1到7之间，**每个星期以周一作为第1天**。

每年的第一个星期可以用如下方法决定（以下四种方法等价）：
- 本年度第一个星期四所在的星期；
- 1月4日所在的星期；
- 本年度第一个至少有4天在同一星期内的星期；
- 星期一在去年12月29日至今年1月4日以内的星期。
推理可得，如果1月1日是星期一、星期二、星期三或者星期四，它所在星期就是本年第一个星期；如果1月1日是星期五、星期六或星期日，则它所在星期就是上一年第52或者53个日历星期；12月28日总是在一年最后一个星期。

[ISO 8601](https://zh.wikipedia.org/wiki/ISO_8601)


*[闰秒]: 是为了补偿地球自转不规则导致的原子时与地球时差异而加入的一秒钟。
